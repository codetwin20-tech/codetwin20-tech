# Code Twin

**Web, photography and motion — more than a web studio.**

Code Twin is a startup based in Dakhla, Morocco. One team for the whole image of your business: we design and build the website, shoot the photography, and craft the films.

## What we do

- Web design and development
- Photography
- Motion graphics and film

## Selected work

- **Boutique Hotel Al Baraka — Dakhla**: a complete hotel website in five languages, with an opening film, a video tour for every room category, direct WhatsApp booking, and a built-in assistant that answers guests at any hour. See [hotel-al-baraka-website](https://github.com/codetwin20-tech/hotel-al-baraka-website).
- **Bex Coffee Dakhla**: website for a specialty coffee house — see the [case repository](https://github.com/mohmedsrii123-lgtm/bex-coffee-dakhla).
